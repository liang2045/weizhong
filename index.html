团队同步地址

填写团队共享的 products.json 文件路径或 HTTP 地址。桌面端任意客户端新增、编辑、排序或导入后，会自动写回这个共享配置；其他安装者点击“更新”即可同步卡片信息。

管理员把导出的产品 JSON 放到共享地址，其他同事点击“更新”即可同步新增或修改的卡片。

拖动产品说明 / 导入导出配置

在产品列表中拖动卡片，或使用卡片右下角的上移/下移按钮调整产品位置；调整后会自动保存在本机。
